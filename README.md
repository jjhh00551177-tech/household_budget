# 家計簿アプリ

収入と支出を記録し、カテゴリ別に管理できるWebアプリケーションです。
Java / Spring Boot の学習を目的に、個人で開発しました。

## 使用技術

| 分類 | 技術 |
|------|------|
| 言語 | Java 17 |
| フレームワーク | Spring Boot 3.5.16 |
| ORM | Spring Data JPA (Hibernate) |
| テンプレートエンジン | Thymeleaf |
| データベース | MySQL 8.0 |
| ビルドツール | Maven |

## 主な機能

- 収支の登録・一覧表示・編集・削除
- カテゴリによる分類（食費・交通費など）
- 収入合計・支出合計・収支の集計表示
- 入力値のバリデーション

## 起動方法

### 前提

- JDK 17
- MySQL 8.0

### データベースの準備

```sql
CREATE DATABASE household_budget;
```

テーブルはアプリ起動時に自動生成されます。

### 環境変数の設定

MySQLのパスワードを環境変数として設定してください。

### 起動

http://localhost:8080/transactions にアクセスしてください。

## 設計上の工夫

### レイヤードアーキテクチャ

Controller / Service / Repository / Entity の4層に分離しています。
DBアクセスはRepository、集計などの処理はService、画面との受け渡しはController
と責務を分けることで、変更の影響範囲を局所化しています。

### DIによる疎結合

`@Autowired` による依存性の注入を用い、各層が具象クラスではなく
インターフェースに依存する構成にしています。

### テーブル間の関連

支出とカテゴリを別テーブルに分離し、`@ManyToOne` で関連付けています。
カテゴリ名を直接持たせず外部キーで参照することで、カテゴリ名の変更が
既存データに影響しない設計としました。

### フォームの共通化

新規登録と編集で同一のテンプレートを使用し、IDの有無によって
送信先とラベルを切り替えることで、重複を避けています。
